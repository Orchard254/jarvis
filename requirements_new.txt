## Platform-Specific Notes

### Windows
- `pycaw` and `comtypes` are required for volume control
- Built-in Windows APIs used for recycle bin operations

### Linux
- Use `pulseaudio-utils` or `pipewire` for volume control
- Install system packages: `sudo apt install portaudio19-dev`

### macOS
- Volume control uses native AppleScript
- No additional dependencies needed

## Installation

### Full Installation
```bash
pip install -r requirements_new.txt
```

### Minimal Installation (Core Only)
```bash
pip install ollama pyaudio speechrecognition pyttsx3 psutil requests
```

### Development Installation
```bash
pip install -r requirements_new.txt
pip install pytest pytest-mock
```

## Dependency Verification

Run the migration script to verify all dependencies:
```bash
python migrate.py
```

Or run the tool tests:
```bash
python test_tools.py
```

## Version Compatibility

All dependencies have been tested with:
- Python 3.10, 3.11, 3.12
- Ollama 0.1.x and above
- Windows 10/11, Ubuntu 22.04+, macOS 12+

## Troubleshooting

### Import Errors
If you see `ImportError: No module named 'xyz'`:
```bash
pip install xyz
```

### Audio Issues on Linux
```bash
sudo apt install portaudio19-dev python3-pyaudio
```

### OpenCV Issues
```bash
pip uninstall opencv-python opencv-contrib-python
pip install opencv-python-headless
```
